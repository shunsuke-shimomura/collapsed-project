# Stack Calculator - Property Based Testing Workshop

このプロジェクトは、プロパティベーステストの学習を目的としたシンプルなスタック計算機の実装です。

## プロダクト仕様

### 概要
スタック（後入れ先出し）データ構造を使用した整数計算機。基本的な算術演算とスタック操作をサポートします。

### 機能
1. **基本スタック操作**
   - `push(value)`: 値をスタックにプッシュ
   - `pop()`: スタックから値をポップ（空の場合はエラー）
   - `peek()`: スタックの先頭を確認（値を削除しない）
   - `size()`: スタックのサイズを取得
   - `is_empty()`: スタックが空かどうかを確認

2. **算術演算**
   - `add()`: スタックから2つの値をポップし、加算結果をプッシュ
   - `subtract()`: スタックから2つの値をポップし、減算結果をプッシュ（後からポップした値 - 先にポップした値）
   - `multiply()`: スタックから2つの値をポップし、乗算結果をプッシュ
   - `divide()`: スタックから2つの値をポップし、除算結果をプッシュ（ゼロ除算はエラー）

3. **エラー処理**
   - スタックが空の時のpop操作
   - 算術演算に必要な要素数が不足している場合
   - ゼロ除算

### 制約
- 整数のみサポート（i32型）
- スタックの最大サイズは1000要素
- 除算は整数除算（小数点以下切り捨て）

## 詳細仕様

### コンストラクタ

#### `new() -> StackCalculator`
- 空のスタック計算機を作成
- max_sizeは1000に設定される
- 初期状態でスタックは空（サイズ0）

#### `with_max_size(max_size: usize) -> StackCalculator`
- 指定されたmax_sizeでスタック計算機を作成
- max_sizeは1以上である必要がある
- max_sizeが0の場合の動作は未定義
- 初期状態でスタックは空（サイズ0）

### 基本スタック操作の詳細

#### `push(value: i32) -> Result<(), CalculatorError>`
**事前条件:**
- なし

**事後条件:**
- 成功時: スタックサイズが1増加し、valueがスタックの先頭に配置される
- スタックサイズがmax_size以上の場合: `StackOverflow`エラーを返す
- エラー時もスタックの状態は変更されない

**不変条件:**
- push成功後、`peek()`は必ずpushした値を返す
- push成功後、`size()`は呼び出し前より1大きい値を返す
- push成功後、`is_empty()`は必ずfalseを返す

#### `pop() -> Result<i32, CalculatorError>`
**事前条件:**
- なし

**事後条件:**
- 成功時: スタックの先頭要素を削除して返す。サイズが1減少する
- スタックが空の場合: `EmptyStack`エラーを返す
- エラー時もスタックの状態は変更されない

**不変条件:**
- `push(x)`直後の`pop()`は必ず`Ok(x)`を返す
- pop成功後、`size()`は呼び出し前より1小さい値を返す
- スタックサイズ1の状態でpop成功後、`is_empty()`はtrueを返す

#### `peek() -> Result<i32, CalculatorError>`
**事前条件:**
- なし

**事後条件:**
- 成功時: スタックの先頭要素を返すが、スタックは変更しない
- スタックが空の場合: `EmptyStack`エラーを返す

**不変条件:**
- peekはスタックの状態を変更しない（`size()`の結果が変わらない）
- `push(x)`直後の`peek()`は必ず`Ok(x)`を返す
- 連続して2回`peek()`を呼んでも同じ値を返す

#### `size() -> usize`
**事前条件:**
- なし

**事後条件:**
- スタック内の要素数を返す

**不変条件:**
- 新規作成時は0を返す
- 返り値は常に0以上、max_size以下
- push成功後は1増加、pop成功後は1減少

#### `is_empty() -> bool`
**事前条件:**
- なし

**事後条件:**
- スタックが空の場合true、そうでない場合false

**不変条件:**
- `is_empty() == true`と`size() == 0`は常に等価
- `is_empty() == false`と`size() > 0`は常に等価
- 新規作成時は必ずtrueを返す

#### `clear()`
**事前条件:**
- なし

**事後条件:**
- スタックを空にする

**不変条件:**
- clear後、`is_empty()`は必ずtrueを返す
- clear後、`size()`は必ず0を返す
- clear後、`pop()`と`peek()`は必ず`EmptyStack`エラーを返す

### 算術演算の詳細

#### `add() -> Result<(), CalculatorError>`
**事前条件:**
- なし

**事後条件:**
- スタックに2個以上の要素がある場合:
  - スタックから2つの値をポップ（先にポップした値をa、後にポップした値をb）
  - a + b の結果をスタックにプッシュ
  - スタックサイズは1減少（2つポップ、1つプッシュ）
- スタックに2個未満の要素しかない場合: `InsufficientOperands`エラーを返す
- エラー時もスタックの状態は変更されない

**不変条件:**
- `push(a); push(b); add()`後、`pop()`は`a + b`を返す
- 加算の可換性: `push(a); push(b); add()`と`push(b); push(a); add()`は同じ結果
- オーバーフロー時の動作は未定義（i32の範囲を超える加算）

**スタック操作の順序:**
```
初期: [... , a, b]  (bが先頭)
↓
b = pop()  → [..., a]
a = pop()  → [...]
push(a + b) → [..., a+b]
```

#### `subtract() -> Result<(), CalculatorError>`
**事前条件:**
- なし

**事後条件:**
- スタックに2個以上の要素がある場合:
  - スタックから2つの値をポップ（先にポップした値をb、後にポップした値をa）
  - a - b の結果をスタックにプッシュ
  - スタックサイズは1減少
- スタックに2個未満の要素しかない場合: `InsufficientOperands`エラーを返す
- エラー時もスタックの状態は変更されない

**不変条件:**
- `push(a); push(b); subtract()`後、`pop()`は`a - b`を返す
- 減算は非可換: `push(5); push(3); subtract()`の結果は2だが、`push(3); push(5); subtract()`の結果は-2
- オーバーフロー時の動作は未定義

**スタック操作の順序:**
```
初期: [... , a, b]  (bが先頭)
↓
b = pop()  → [..., a]
a = pop()  → [...]
push(a - b) → [..., a-b]
```

#### `multiply() -> Result<(), CalculatorError>`
**事前条件:**
- なし

**事後条件:**
- スタックに2個以上の要素がある場合:
  - スタックから2つの値をポップ（先にポップした値をa、後にポップした値をb）
  - a * b の結果をスタックにプッシュ
  - スタックサイズは1減少
- スタックに2個未満の要素しかない場合: `InsufficientOperands`エラーを返す
- エラー時もスタックの状態は変更されない

**不変条件:**
- `push(a); push(b); multiply()`後、`pop()`は`a * b`を返す
- 乗算の可換性: `push(a); push(b); multiply()`と`push(b); push(a); multiply()`は同じ結果
- ゼロとの乗算: `push(0); push(x); multiply()`の結果は常に0
- オーバーフロー時の動作は未定義

**スタック操作の順序:**
```
初期: [... , a, b]  (bが先頭)
↓
b = pop()  → [..., a]
a = pop()  → [...]
push(a * b) → [..., a*b]
```

#### `divide() -> Result<(), CalculatorError>`
**事前条件:**
- なし

**事後条件:**
- スタックに2個以上の要素があり、除数が0でない場合:
  - スタックから2つの値をポップ（先にポップした値をb、後にポップした値をa）
  - a / b の整数除算結果をスタックにプッシュ
  - スタックサイズは1減少
- スタックに2個未満の要素しかない場合: `InsufficientOperands`エラーを返す
- 除数（b）が0の場合: `DivisionByZero`エラーを返す
- エラー時もスタックの状態は変更されない（両方の値を元に戻す）

**不変条件:**
- `push(a); push(b); divide()`成功時、`pop()`は`a / b`（整数除算）を返す
- 除算は非可換: `push(6); push(3); divide()`の結果は2だが、`push(3); push(6); divide()`の結果は0
- 整数除算の切り捨て: `push(7); push(2); divide()`の結果は3
- 負の数の除算: Rustの整数除算規則に従う（ゼロ方向への切り捨て）
  - `push(-7); push(2); divide()` → -3
  - `push(7); push(-2); divide()` → -3
  - `push(-7); push(-2); divide()` → 3
- ゼロ除算時の例外安全性: エラー発生時、スタックは操作前の状態に戻る

**スタック操作の順序:**
```
初期: [... , a, b]  (bが先頭)
↓
b = pop()  → [..., a]
a = pop()  → [...]
if b == 0:
  push(a)  → [..., a]
  push(b)  → [..., a, b]
  return DivisionByZero
else:
  push(a / b) → [..., a/b]
```

### エラー処理の詳細

#### `CalculatorError::EmptyStack`
- `pop()`または`peek()`をスタックが空の状態で呼び出した際に返される
- エラー発生時、スタックの状態は変更されない

#### `CalculatorError::InsufficientOperands`
- 算術演算（`add`, `subtract`, `multiply`, `divide`）をスタックに2個未満の要素しかない状態で呼び出した際に返される
- エラー発生時、スタックの状態は変更されない

#### `CalculatorError::DivisionByZero`
- `divide()`で除数が0の場合に返される
- エラー発生時、スタックの状態は変更されない（ポップした2つの値を元に戻す）

#### `CalculatorError::StackOverflow`
- `push()`でスタックサイズがmax_size以上の状態で呼び出した際に返される
- エラー発生時、スタックの状態は変更されない（値はプッシュされない）

### ワークショップの学習目標
このプロジェクトを通じて以下のプロパティベーステストの概念を学習します：

1. **不変条件（Invariants）**
   - スタックのサイズは常に非負数
   - push後のサイズは1増加
   - pop後のサイズは1減少（空でない場合）

2. **逆操作（Inverse Operations）**
   - push(x) → pop() == x
   - 連続するpush/popの組み合わせ

3. **数学的性質**
   - 加算の可換性
   - 乗算の可換性
   - 演算の結合性

4. **エラー条件**
   - 空スタックでのpop/peek操作
   - 不十分な要素数での算術演算
   - ゼロ除算の処理
